# الخطة الرئيسية لـ ATsoft ERP — ATsoft ERP Master Plan

**الإصدار:** 1.0  
**تاريخ الإصدار:** 2026-08-02  
**الحالة:** موثقة — خارطة طريق التنفيذ المتدرجة

---

## 1. المبادئ الحاكمة

1. كل مرحلة تُبنى كشرائح رأسية مختبرة: قاعدة بيانات آمنة → backend → صلاحيات → frontend → i18n → اختبارات → إثبات.
2. لا تُفتح نطاقات غير معتمدة (المادة 28 في الدستور).
3. كل تغيير يحفظ البيانات القائمة ويعزز عزل المستأجر.
4. كل مرحلة تنتهي بتقرير إثبات وتحديث حالة.

## 2. المراحل

### المرحلة 0 — إعادة هيكلة التنظيم والمصنع (الأساس)

**الهدف:** إعادة هيكلة الأصول التشغيلية والتنظيمية لتتكيف مع شركات مختلفة البنية، دون كسر الوحدات القائمة.

**النطاق المعتمد:**

- نموذج `OrganizationalUnit` شجري جديد يرتبط بالشركة والفرع والوحدة الأم (اختياري)، مع كود ونوع وحالة.
- الإبقاء على نموذج `Machine` مع عداد/موقع الماكينة كميزة توسيعية آمنة.
- نموذج `MaintenanceWorkOrder` جديد يربط الصيانة بالمخزون والتكلفة بعزل كامل للمستأجر.
- ترسيخ قواعد التعبئة التلقائية والسياق التشغيلي في وحدات التحكم.

**مخرجات:** ترحيل آمن (nullable → backfill → constraints)، API بصلاحيات، صفحات frontend، ترجمات عربية/إنجليزية، اختبارات مستأجر، تقرير إثبات، قالب تدقيق.

### المرحلة 1 — وحدة الإنتاج (شرائح رأسية)

**الهدف:** بناء مجال الإنتاج تدريجياً دون تكرار الكيانات القائمة.

**الشريحة 1.1:** البيانات الرئيسية للإنتاج (مستقلة عن الصيانة).
**الشريحة 1.2:** الورديات والتخصيصات التشغيلية.
**الشريحة 1.3:** معايير قدرة المنتج.
**الشريحة 1.4:** أوامر الإنتاج.
**الشريحة 1.5:** تشغيلات/جلسات التنفيذ وتسجيل الناتج.
**الشريحة 1.6:** أسباب التوقف والخسارة، والهالك وإعادة العمل.
**الشريحة 1.7:** استهلاك المواد واستلام السلع التامة.
**الشريحة 1.8:** الجودة والتكلفة.
**الشريحة 1.9:** تقارير OEE والأداء.

### المرحلة 2 — تعميق التشغيل والتحليل

**الهدف:** تعميق التكاليف التشغيلية والمقاييس دون إنشاء حقائق مالية موازية.

**النطاق:** مراكز التكلفة، معاملة التكلفة الذرية، MTBF/MTTR/OEE من السجلات الذرية، وتقارير التكلفة والموثوقية.

### المرحلة 3 — نضج الإصدار

**الهدف:** نضج الإصدار والتوثيق والتدريب والأدوات التشغيلية.

**النطاق:** توثيق المستخدم، وحزم النشر، والأدوات المساعدة، وأتمتة التدقيق، وتحسين الأداء.

## 3. أولوية التنفيذ

عند تكرار المهام المستقبلية:

1. أكمل النطاق المتروك قبل النطاق الجديد (الإثبات، والالتزام، والدفع).
2. نفّذ المرحلة 0 قبل وحدة الإنتاج.
3. نفّذ وحدة الإنتاج بالترتيب المحدد في الشريحة.
4. لا تنتقل لمرحلة إلا بعد مراجعة إثبات المرحلة السابقة.

## 4. القواعد عند انحراف الخطة

- عندما يطلب المستخدم تغييراً يقع خارج المراحل، سجّله كملاحظة واطلب اعتماداً قبل التنفيذ.
- عندما يتعارض تنفيذان، طبق الدستور ثم ملفات القواعد ثم هذا الملف.
- عند الغموض في النطاق، استخدم أصغر تنفيذ آمن وحقق النتيجة الكاملة.
