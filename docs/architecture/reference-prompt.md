## ملخص ما يفرضه العقد تلقائياً

- لا صفحات/APIs مكررة — البحث أولاً ثم البناء على الموجود.
- تقليل الإدخال اليدوي (Auto-populate من Active Company/Branch وجلسة الدخول).
- مكونات الإدخال والحوارات والأخطاء المشتركة نفسها.
- لا Raw Keys، دعم عربي/إنجليزي وRTL/LTR بالكامل.
- Audit، صلاحيات، Multi-company، Runtime Proof، UX موحد.
- شريحة رأسية كاملة + بوابات تحقق + تقرير نهائي موحد.
