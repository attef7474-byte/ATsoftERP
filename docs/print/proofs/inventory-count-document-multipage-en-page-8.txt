Notes
Quantities are recorded count values in the source product unit. System quantity is the stored count-time snapshot
captured on the count line, never the current inventory balance. Difference is the recorded count value calculated by
the system as counted quantity minus system quantity; it is not recalculated from current stock. The current count
workflow has no blind-count mode, so the document shows the same system, counted and difference values the
authorized count screen already shows. Quantities with different or missing units are never summed and no document
quantity total or valuation is computed. Counter and verifier display names are not supplied by the count contract, so
those identities are omitted rather than replaced with identifiers. This document is not a ledger reconciliation.
Annual full count of the spare parts store.
