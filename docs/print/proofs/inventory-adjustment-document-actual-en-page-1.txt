Quantities are the recorded adjustment values in the source product unit. System quantity is the stored count-time
snapshot captured on the adjustment line, never the current inventory balance. Counted quantity and difference are the
recorded adjustment values; difference keeps the stored sign (counted quantity minus system quantity) and is not
recalculated from current stock. No after quantity is stored and none is derived. Legacy adjustment posting creates no
inventory movement, so no movement reference is printed. The adjustment has no type/method field and none is
invented. Quantities with different or missing units are never summed and no document quantity total, cost, value or
valuation is computed. Readable user names, lot/batch/serial data and cost are not supplied by the adjustment detail
contract, so they are omitted rather than replaced with identifiers. This document is not a ledger reconciliation.
