# قيود وضوابط المخزون — العربية

## الضوابط المطبقة
| الضابط | التنفيذ | الحالة |
|-------|---------|--------|
| القفل: PERIOD_LOCK | يمنع الترحيل في نطاق تاريخي | مطبق |
| القفل: WAREHOUSE_LOCK | يمنع الترحيل لمستودع | مطبق |
| القفل: GLOBAL_INVENTORY_LOCK | يمنع كل ترحيل المخزون | مطبق |
| القفل: USER_LOCK | يمنع ترحيل المخزون لمستخدم | مطبق |
| القفل: TRANSACTION_TYPE_LOCK | يمنع أنواع حركة محددة | مطبق |
| سير عمل حالة المستند | مسودة → مقدم → معتمد → مرحّل | مطبق |
| الحد الأدنى لطول السبب | 5 أحرف مطلوبة | مطبق |
| سجل التدقيق | جميع تغييرات الحالة مسجلة | مطبق |
| التحكم بالصلاحيات | تفويض لكل عملية | مطبق |
| فحص كفاية المخزون | يمنع الحركة الصادرة عند نقص الرصيد | مطبق |
| عدم قابلية تعديل المستندات المرحّلة | لا تعديل/حذف بعد الترحيل | مطبق |
| مصدر التحويل ≠ الوجهة | يمنع التحويل لنفس المستودع | مطبق |

## القيود المعروفة
| القيد | التأثير | الحل البديل | مخطط؟ |
|-------|---------|-------------|-------|
| LOCATION_LOCK غير مطبق | لا يمكن القفل بموقع فرعي | استخدام WAREHOUSE_LOCK | غير مؤكد |
| ITEM_LOCK غير مطبق | لا يمكن قفل أصناف فردية | استخدام TRANSACTION_TYPE_LOCK | غير مؤكد |
| تجاوز القفل غير مطبق | لا آلية تجاوز | إلغاء القفل قبل الترحيل | مستقبلاً |
| المالية غير مفعلة | لا COGS، لا قيود يومية | المخزون مستقل | دفعة منفصلة |
| الموارد البشرية غير مفعلة | لا مزامنة موظف→مستخدم | إدارة المستخدمين يدوياً | دفعة منفصلة |
| المبيعات غير مفعلة | لا رابط أمر بيع→تسليم | صرف المخزون عبر التسوية | دفعة منفصلة |
| المشتريات غير مفعلة | لا رابط أمر شراء→استلام | استلام المخزون عبر الاستلام التشغيلي | دفعة منفصلة |
| لا طريقة تقييم مخزون | كمية فقط، لا تكلفة | غير مطبق | تحسين مستقبلي |
| لا تنبيهات إعادة طلب | لا اقتراحات تلقائية | مراقبة يدوية | تحسين مستقبلي |
| لا تتبع دفعات/أرقام تسلسلية | تتبع بالمنتج فقط | غير مطبق | تحسين مستقبلي |
