# دليل تشغيل المخزون — العربية

## 1. مقدمة
وحدة المخزون تدير حركات المخزون عبر المؤسسة بما في ذلك مخزون الصيانة، التحويلات بين المستودعات، الجرد الفعلي، والاستلام التشغيلي.

**ما تغطيه الوحدة:**
- الأرصدة الافتتاحية، تسويات المخزون، التحويلات بين المستودعات
- الاستلام التشغيلي (بدون مشتريات)
- صرف قطع غيار الصيانة وإرجاعها
- الجرد الفعلي والتحكم بالفروقات
- دفتر الأستاذ والتسوية
- التقارير، تتبع المصادر، والاستثناءات
- أقفال المخزون، التدقيق، والصلاحيات

**ما لا تغطيه الوحدة:**
- المالية (غير مفعلة)
- المشتريات (غير مفعلة)
- المبيعات (غير مفعلة)
- الموارد البشرية (غير مفعلة)

## 2. أدوار المستخدمين
- **أمين المستودع**: إنشاء التحويلات والتسويات والجرد والاستلام التشغيلي
- **مستخدم الصيانة**: صرف قطع الغيار لطلبات الصيانة وإرجاع القطع غير المستخدمة
- **مشرف الصيانة**: الموافقة على معاملات مخزون الصيانة
- **مشرف المخزون**: الموافقة على التسويات والجرد وإدارة الأقفال
- **المسؤول**: تعيين الصلاحيات وإدارة تكوين النظام
- **المدقق/المشاهد**: قراءة التقارير ودفتر الأستاذ وسجل التدقيق

## 3. التنقل
صفحات المخزون موجودة تحت `/admin/inventory/`:
- التقارير: `/admin/inventory/reports`
- بطاقة المخزون: `/admin/inventory/reports/stock-card`
- تتبع المصادر: `/admin/inventory/reports/traceability`
- دفتر الأستاذ: `/admin/inventory/ledger`
- التسوية: `/admin/inventory/reconciliation`
- الأرصدة الافتتاحية: `/admin/inventory/opening-balances`
- تسويات المخزون: `/admin/inventory/stock-adjustments`
- التحويلات: `/admin/inventory/transfers`
- الاستلام التشغيلي: `/admin/inventory/operational-receipts`
- الجرد الفعلي: `/admin/inventory/physical-counts`
- الأقفال: `/admin/inventory/locks`
- تدقيق الحوكمة: `/admin/inventory/governance-audit`

## 4. البيانات الأساسية المطلوبة
قبل استخدام عمليات المخزون، يجب أن تتوفر:
- المنتجات أو قطع الغيار
- المستودعات
- المواقع (اختياري)
- مستخدمين مع صلاحيات محددة

## 5. الرصيد الافتتاحي
**الاستخدام:** عند البدء في إعداد المخزون أو إدخال منتج جديد.
1. انتقل إلى الأرصدة الافتتاحية
2. اضغط إنشاء
3. اختر المستودع، أدخل السبب
4. أضف البنود (منتج، كمية)
5. قدم للموافقة
6. قم بترحيل المستند

## 6. تسوية المخزون
### تسوية زيادة
1. انتقل إلى تسويات المخزون
2. اضغط إنشاء، اختر اتجاه زيادة
3. أدخل السبب (مطلوب)
4. أضف البنود
5. قدم، وافق، ثم رحّل
### تسوية نقص
نفس الخطوات ولكن اختر اتجاه نقص.

## 7. التحويل بين المستودعات
1. انتقل إلى التحويلات
2. اضغط إنشاء
3. اختر مستودع المصدر والوجهة
4. أضف البنود
5. رحّل

## 8. الاستلام التشغيلي
1. انتقل إلى الاستلام التشغيلي
2. اضغط إنشاء
3. اختر المستودع والسبب
4. أضف البنود
5. رحّل
**ملاحظة:** لا ينشئ أمر شراء أو فاتورة مورد.

## 9. صرف وإرجاع الصيانة
### صرف قطع الغيار
افتح طلب الصيانة، أضف قطع الغيار، ثم اصرف المخزون.
### إرجاع قطع الغيار
افتح الطلب، ارجع الكمية غير المستخدمة.

## 10. الجرد الفعلي
1. أنشئ جرداً لمستودع
2. أدخل الكمية المعدودة
3. اشرح الفروقات الكبيرة
4. قدم للموافقة ورحّل

## 11. دفتر الأستاذ والتسوية
يعرض جميع حركات المخزون. التسوية تقارن الرصيد الحالي بالمتوقع.

## 12. التقارير
جميع التقارير للقراءة فقط.

## 13. الأقفال والتدقيق
أنشئ قفلاً لمنع الترحيل خلال فترة محددة.

## 14. الصلاحيات
كل عملية مخزون تتطلب صلاحية محددة.

## 15. استكشاف الأخطاء
راجع دليل استكشاف الأخطاء.

## 16. القيود
راجع وثيقة القيود والضوابط للتفاصيل الكاملة.
