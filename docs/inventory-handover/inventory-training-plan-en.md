# Inventory Training Plan — English

## Module 1: Inventory Overview
- **Audience:** All users
- **Objectives:** Understand inventory scope, what is/is not covered, navigation
- **Exercise:** Navigate to each inventory page and identify its purpose
- **Pass criteria:** Can list 5 inventory operations

## Module 2: Master Data Prerequisites
- **Audience:** Administrators, Inventory Supervisors
- **Objectives:** Understand what data must exist before inventory operations
- **Exercise:** Verify products, warehouses, and user permissions exist

## Module 3: Opening Balance
- **Audience:** Warehouse Officers, Inventory Supervisors
- **Objectives:** Create, approve, and post opening balances
- **Exercise:** Create an opening balance for a test warehouse with 2 products
- **Pass criteria:** Stock card shows the opening balance

## Module 4: Stock Adjustment
- **Audience:** Warehouse Officers, Inventory Supervisors
- **Objectives:** Create IN/OUT adjustments, approve, post
- **Exercise:** Create an adjustment IN for one product, verify in ledger

## Module 5: Warehouse Transfer
- **Audience:** Warehouse Officers
- **Objectives:** Create and post a transfer
- **Exercise:** Transfer 5 units from warehouse A to B, verify both movements

## Module 6: Operational Receiving
- **Audience:** Warehouse Officers
- **Objectives:** Create and post an operational receipt
- **Exercise:** Receive 10 units via operational receipt, verify no PO created

## Module 7: Maintenance Issue/Return
- **Audience:** Maintenance Users, Supervisors
- **Objectives:** Issue spare parts to a request, return unused parts
- **Exercise:** Issue 3 units to a maintenance request, then return 1 unit

## Module 8: Physical Count and Variance
- **Audience:** Warehouse Officers, Inventory Supervisors
- **Objectives:** Create count, enter counted quantities, post variance
- **Exercise:** Count 2 products, create variance, post, verify in reconciliation

## Module 9: Ledger and Reconciliation
- **Audience:** Inventory Supervisors, Auditors
- **Objectives:** Read ledger, understand reconciliation difference
- **Exercise:** Find a movement in ledger, trace it to source document

## Module 10: Reports and Traceability
- **Audience:** All users
- **Objectives:** Read stock card, movement register, traceability
- **Exercise:** Pick one product, trace its stock card and identify source documents

## Module 11: Locks and Audit
- **Audience:** Inventory Supervisors, Administrators
- **Objectives:** Create, activate, deactivate locks; verify audit trail
- **Exercise:** Create a PERIOD_LOCK, verify blocked posting, check audit log

## Module 12: Permissions and Security
- **Audience:** Administrators
- **Objectives:** Understand permission model, assign roles
- **Exercise:** Identify which permissions are needed for each operation

## Module 13: Troubleshooting
- **Audience:** All users
- **Objectives:** Handle common errors
- **Exercise:** Given scenarios (403, missing reason, no data), identify cause and action

## Module 14: Practical Assessment
- **Duration:** 2 hours
- **Scenarios:**
  1. Create and post an opening balance (2 products)
  2. Create a stock adjustment OUT with reason
  3. Trace one movement to its source document using traceability report
  4. Read stock card for one product, identify opening and closing balance
  5. Identify a reconciliation difference and explain the next step
  6. Explain what happens when you try to post under an active lock
  7. Identify the required permission for creating a stock adjustment
- **Pass criteria:** 6/7 scenarios correctly completed
