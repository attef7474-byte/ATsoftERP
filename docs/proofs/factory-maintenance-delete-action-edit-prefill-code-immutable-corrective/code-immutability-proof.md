# Code Immutability Proof

## Backend

### Machines (maintenance.service.ts)
```typescript
async updateMachine(id: string, dto: UpdateMachineDto) {
  const existing = await this.findOneMachine(id);
  if (dto.code && dto.code !== existing.code) {
    throw new BadRequestException('Code cannot be changed after creation');
  }
  const { code, ...rest } = dto as any; // Strip code from update
}
```

### Number Sequences
- Code is auto-generated via `generateNumberAtomic()` on create
- Number Sequences never incremented on edit
- Known sequences: 'MACHINE', 'MACHINE_PART', 'MAINTENANCE_REQUEST'

## Frontend

### Create Mode
All 16 pages show auto-generated message instead of editable code field:
```tsx
<p className="text-sm text-gray-500 italic">{t('common.codeAutoGenerated')}</p>
```

### Edit Mode
All 16 pages show code as read-only:
```tsx
<Input label={t('common.code')} value={form.code} disabled />
<p className="text-xs text-gray-500 mt-1">{t('common.codeImmutableHint')}</p>
```

### API Payload
Code is excluded from edit save payload:
```typescript
const { code, ...payload } = form;
// or
delete payload.code;
```

### Dedicated Edit Pages (machines/[id]/edit)
- Code field always disabled (not controlled by isReadOnly flag)
- Code validation removed from edit validation
- Code excluded from PATCH payload
