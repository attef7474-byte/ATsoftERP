# Raw i18n Keys Proof — Before / After

## Problem

Three common i18n keys were referenced in component templates but missing from the locale files:

- `common.add`
- `common.select`
- `common.new`

This caused Angular/Next.js i18n pipes to output the raw key string (e.g. "common.add") instead of a translated label.

## Affected Pages

| Page | Key | Before (Rendered) | After (Rendered) |
|---|---|---|---|
| Machine Categories | `common.add` | `common.add` | `Add` (EN) / `إضافة` (AR) |
| Machine Categories | `common.select` | `common.select` | `Select` (EN) / `اختيار` (AR) |
| Spare Parts | `common.add` | `common.add` | `Add` (EN) / `إضافة` (AR) |
| Spare Parts | `common.select` | `common.select` | `Select` (EN) / `اختيار` (AR) |
| Maintenance Personnel | `common.add` | `common.add` | `Add` (EN) / `إضافة` (AR) |
| Maintenance Personnel | `common.select` | `common.select` | `Select` (EN) / `اختيار` (AR) |
| Maintenance Personnel | `common.new` | `common.new` | `New` (EN) / `جديد` (AR) |

## Additional Keys Added

| Key | English | Arabic | Purpose |
|---|---|---|---|
| `common.autoGenerated` | Auto-generated | تلقائي | Shown next to auto-code fields |
| `common.linked` | Linked | مرتبط | Personnel grid status column |
| `common.unlinked` | Unlinked | غير مرتبط | Personnel grid status column |
| `maintenance.userAccount` | User Account | حساب المستخدم | Label for the userId F9 lookup field |

## Verification

- All three pages (Machine Categories, Spare Parts, Maintenance Personnel) were rendered and inspected.
- No raw i18n key strings (e.g. `common.add`) appeared in the rendered HTML.
- The Next.js `useTranslation()` hook resolves keys through the `common` and `maintenance` namespaces.
- Both English and Arabic locales were updated with identical key sets.

## Proof Files

- `/src/locales/en/common.json` — includes `add`, `select`, `new`, `autoGenerated`, `linked`, `unlinked`
- `/src/locales/ar/common.json` — includes `إضافة`, `اختيار`, `جديد`, `تلقائي`, `مرتبط`, `غير مرتبط`
- `/src/locales/en/maintenance.json` — includes `userAccount`
- `/src/locales/ar/maintenance.json` — includes `حساب المستخدم`
