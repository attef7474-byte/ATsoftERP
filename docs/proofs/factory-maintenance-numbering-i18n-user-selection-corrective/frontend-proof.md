## F9 User Lookup Component

- Added to both Create and Edit forms for Maintenance Personnel.
- Opens a modal dialog listing users from `GET /api/v1/users`.
- Selecting a user populates the `userId` field on the personnel record.
- Clears the field if "No Account" is chosen (null userId).
- See `f9-user-lookup-proof.md` for detailed verification.
