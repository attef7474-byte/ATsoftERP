## Cross-Namespace Reference

The `barcode-overview` child uses label `barcodes.overview.title` (from `barcodes.ts`) instead of `navigation.*` key. All other items use `navigation.*` keys.

This means the overview label is loaded from a different i18n namespace than all other sidebar items, creating a consistency risk.
