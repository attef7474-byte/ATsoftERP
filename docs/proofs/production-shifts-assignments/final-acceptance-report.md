## ATsoftERP — Phase 1.2: Production Shifts & Assignments (ورديات الإنتاج والتخصيصات)

---

### ملخص العمل

اكتملت الشريحة الرأسية الكاملة لـ"ورديات الإنتاج والتخصيصات" من قاعدة البيانات حتى الواجهة:

1. **Backend**: 6 خدمات ومتحكمات في `production-shifts` (الورديات، قوالب الورديات، تقويمات الورديات، تخصيصات الورديات، التخصيصات التشغيلية، والكادر التشغيلي للقراءة).
2. **Database**: ترحيل منقّح (7 جداول) دون أي فقد بيانات أو إعادة بناء.
3. **Numbering**: 5 تسلسلات عالمية (`PS-`، `PST-`، `PSC-`، `PSA-`، `POA-`) — إجمالي تسلسلات النظام 53.
4. **Permissions**: 30 مفتاح صلاحية جديد — إجمالي مفاتيح super admin 538.
5. **Frontend**: 5 صفحات إدارية جديدة + 6 محولات F9 + قسم تنقل "الورديات والتخصيصات".
6. **i18n**: نطاق `production.*` موسع بالعربية والإنجليزية مع RTL/LTR.

### التحقق الأمني والعزل البيني

- ✓ كل مسار محمي بـ JWT + صلاحية backend.
- ✓ عزل الشركات: قراءة/تعديل من شركة أخرى → 404؛ إسناد مرجع عبر الشركات → 400.
- ✓ لا يُثق بشركة/فرع من frontend — تُفرض من السياق التشغيلي الموثّق.
- ✓ مفاتيح صلاحية مُعرّفة ومُبعثرة ومُفروضة في backend ومُستخدمة في frontend ومُترجمة.
- ✓ كل عملية حساسة مسجلة في سجل التدقيق مع المستخدم/الشركة/الفرع/النوع/الإجراء/الطوابع الزمنية.
- ✓ لا أسرار أو مفاتيح مكشوفة.

### الحفاظ على البيانات

- ✓ لا `migrate reset` ولا حذف قاعدة بيانات ولا `db push` غير مراجع.
